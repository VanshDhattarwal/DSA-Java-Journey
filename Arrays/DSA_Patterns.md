# 🧠 DSA Patterns

This file contains the patterns I learn while solving Data Structures and Algorithms problems. Instead of memorizing solutions, I focus on recognizing patterns and applying them to new problems.

---

# 📌 1. Frequency Counting

### Description
Count how many times an element appears in the array.

### Questions Solved
- ✅ Majority Element (LeetCode 169)

### Time Complexity
- Brute Force: O(n²)
- HashMap: O(n)

### Key Learning
- Count occurrences of each element.
- Compare the frequency with the required condition.
- Return the element, not its frequency.

# 📌 2. Two Pointers

### Description
Use two indices to solve problems efficiently without extra space.

### Questions Solved
- ✅ Remove Element (LeetCode 27)
- ✅ Remove Duplicates from Sorted Array (LeetCode 26)
- ✅ Move Zeroes (LeetCode 283)
- ✅ Best Time to Buy and Sell Stock (LeetCode 121)

### Key Learning
- Maintain read and write pointers.
- Move pointers based on the problem condition.
- Avoid unnecessary extra arrays.

# 📌 3. Simulation

### Description
Simulate the process exactly as described.

### Questions Solved
- ✅ Plus One (LeetCode 66)

### Key Learning
- Process from the end of the array.
- Handle carry correctly.
- Create a new array only when required.
